## 🎯 Bienvenue sur RIA Check & Go

**RIA Check & Go** est votre assistant intelligent pour évaluer et améliorer la conformité de vos systèmes d'Intelligence Artificielle avec le **Règlement européen sur l'IA (AI Act)**.

### À qui s'adresse cette solution ?

✅ **Fournisseurs de systèmes d'IA** : Développeurs, éditeurs de logiciels  
✅ **Déployeurs de systèmes d'IA** : Entreprises utilisant des solutions IA  
✅ **Responsables conformité** : DPO, RSSI, juristes  
✅ **Directions générales** : Pour comprendre leurs obligations légales

## 📋 Utilisation détaillée

### Module 1 : Diagnostic de conformité

#### Remplir les informations entreprise

**Champs obligatoires :**

| Champ | Description | Exemple |
|-------|-------------|---------|
| **Nom entreprise** | Raison sociale complète | TechnoIA Solutions SARL |
| **Secteur** | Domaine d'activité | Santé, Finance, Transport... |
| **Type IA** | Description système IA | "Chatbot client", "Analyse prédictive"... |

💡 **Astuce :** Soyez précis dans la description de votre système d'IA pour obtenir des résultats plus pertinents.

#### Répondre au questionnaire

**5 questions stratégiques vous seront posées :**

**Question 1 : Techniques de manipulation**
> "Votre système d'IA utilise-t-il des techniques de manipulation subliminale ?"

- ⚠️ **Critique** : Si "Oui" → Pratique interdite (Article 5 RIA)
- ℹ️ Exemples : Manipulation comportementale, exploitation de vulnérabilités psychologiques

**Question 2 : Contexte critique**
> "Votre système est-il utilisé dans un secteur critique ?"

- 🔴 **Haut risque** : Santé, transports, éducation, justice, emploi...
- 📋 Référence : Annexe III du RIA

**Question 3 : Données biométriques**
> "Votre système traite-t-il des données biométriques ?"

- 🔴 **Haut risque** : Reconnaissance faciale, empreintes digitales, voix...
- 📋 Référence : Article 10 RIA

**Question 4 : Interaction automatique**
> "Votre système interagit-il avec des utilisateurs sans supervision humaine ?"

- 🟡 **Risque modéré** : Chatbots, assistants virtuels autonomes...
- 📋 Référence : Article 52 RIA (transparence)

**Question 5 : Documentation**
> "Disposez-vous d'une documentation technique complète ?"

- ✅ **Conformité** : Essentiel pour tous systèmes à haut risque
- 📋 Référence : Annexe IV RIA

**Options de réponse :**
- ✅ **Oui** : L'affirmation s'applique à votre système
- ❌ **Non** : L'affirmation ne s'applique pas
- ❓ **Je ne sais pas** : Vous avez un doute (recommandation : consulter un expert)

### Module 2 : Comprendre vos résultats

#### Lecture du score

Votre score est calculé sur **100 points** et détermine votre niveau de conformité :

```
┌─────────────────────────────────────┐
│  0-29  │ 🟢 Risque Minimal          │
│ 30-59  │ 🟡 Risque Modéré           │
│ 60-100 │ 🔴 Risque Élevé            │
│ ALERTE │ ⛔ Risque Inacceptable     │
└─────────────────────────────────────┘
```

#### Niveaux de risque expliqués

**🟢 Risque Minimal**
- ✅ Peu ou pas d'obligations légales contraignantes
- 📝 Recommandation : Restez informé des évolutions réglementaires
- 💼 Bonnes pratiques volontaires recommandées

**🟡 Risque Modéré**
- 📢 **Obligations de transparence** (Article 52)
- 📝 Informer clairement les utilisateurs de l'usage d'IA
- 💼 Documentation minimale requise

**🔴 Risque Élevé**
- ⚠️ **Obligations strictes** (Titre III du RIA)
- 📋 Système de gestion des risques obligatoire
- 📊 Gouvernance stricte des données
- 📄 Documentation technique complète (Annexe IV)
- 🔍 Enregistrement dans le registre UE
- 👤 Supervision humaine requise

**⛔ Risque Inacceptable**
- 🚫 **PRATIQUES INTERDITES** (Article 5)
- ❌ Mise sur le marché/utilisation interdite
- ⚡ Action immédiate requise : Arrêt du système
- 💼 Consultation juridique urgente recommandée

#### Vos obligations détaillées

Pour chaque obligation identifiée, le rapport indique :

| Élément | Description |
|---------|-------------|
| 📌 **Titre** | Nom de l'obligation |
| 📖 **Description** | Explication claire |
| 📋 **Article RIA** | Référence légale |
| ⏰ **Échéance** | Délai de mise en conformité |
| 🎯 **Actions** | Étapes recommandées |

#### Exemples d'obligations

**📊 Système de gestion des risques (Article 9)**
```
✓ Identifier tous les risques potentiels
✓ Évaluer probabilité et impact
✓ Mettre en place des mesures d'atténuation
✓ Documenter et réviser annuellement
```

**📄 Documentation technique (Annexe IV)**
```
✓ Description complète du système
✓ Architecture et design
✓ Données d'entraînement utilisées
✓ Métriques de performance
✓ Procédures de test
```

**🔍 Enregistrement UE**
```
✓ Inscription au registre européen
✓ Mise à jour en cas de modification
✓ Information des autorités nationales
```

## ❓ Foire Aux Questions (FAQ)

### Questions générales

**Q1 : Le diagnostic RIA Check & Go est-il gratuit ?**  
R : Oui, le diagnostic en ligne et le rapport PDF sont 100% gratuits et sans engagement.

**Q2 : Mes données sont-elles sécurisées ?**  
R : Absolument. Nous appliquons le RGPD et chiffrons toutes vos données. Voir notre [Politique de confidentialité](#politique-confidentialite).

**Q3 : Puis-je refaire plusieurs diagnostics ?**  
R : Oui, vous pouvez réaliser autant de diagnostics que nécessaire pour différents systèmes d'IA.

**Q4 : Le rapport a-t-il une valeur légale ?**  
R : Le rapport est un outil d'aide à la décision, mais ne constitue pas une certification officielle.

### Questions sur le RIA

**Q5 : Quand le RIA entre-t-il en vigueur ?**  
R : Le RIA est applicable progressivement :
- Février 2025 : Pratiques interdites (Art. 5)
- Août 2026 : Systèmes à haut risque (Titre III)
- Août 2027 : Obligations de transparence (Titre IV)

**Q6 : Qui est concerné par le RIA ?**  
R : Tous les fournisseurs et déployeurs de systèmes d'IA dans l'UE, ainsi que les systèmes utilisés dans l'UE même si le fournisseur est hors UE.

**Q7 : Quelles sont les sanctions en cas de non-conformité ?**  
R : Les amendes peuvent atteindre :
- **35M€ ou 7% CA** : Pratiques interdites
- **15M€ ou 3% CA** : Non-conformité systèmes haut risque
- **7,5M€ ou 1,5% CA** : Informations inexactes

### Questions techniques

**Q8 : L'application fonctionne-t-elle hors ligne ?**  
R : Non, une connexion internet est nécessaire pour réaliser le diagnostic et générer le rapport.

**Q9 : Sur quels appareils puis-je utiliser RIA Check & Go ?**  
R : L'application est compatible :
- 💻 Ordinateur (Windows, Mac, Linux)
- 📱 Smartphone (iOS, Android)
- 📱 Tablette (iOS, Android)

**Q10 : Puis-je sauvegarder mon diagnostic pour le reprendre plus tard ?**  
R : Actuellement, le diagnostic doit être complété en une seule session. Cette fonctionnalité sera disponible dans une prochaine version.
